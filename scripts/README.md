# Scripts

Utility scripts for the jAIMSnet platform.

## Planned Scripts

| Script | Purpose |
|--------|---------|
| `backup-pg.sh` | PostgreSQL database backup |
| `verify-cluster.sh` | Verify cluster health and component status |
| `generate-secrets.sh` | Generate initial secrets for development |
| `rotate-keys.sh` | Rotate LLM provider API keys |
| `export-evidence.sh` | Export compliance evidence |

## Usage

Scripts will be added as the platform is implemented. All scripts include usage information when run with `--help`.

## Status

🟡 Scripts are planned and will be implemented alongside the platform components they support.
