# Compliance

Compliance frameworks, organizational policies, and evidence collection for the jAIMSnet platform.

## Structure

```
compliance/
├── frameworks/       # Compliance framework mappings
│   ├── soc2/         # SOC 2 Type II
│   ├── hipaa/        # HIPAA
│   ├── gdpr/         # GDPR
│   ├── nist/         # NIST 800-53
│   ├── iso27001/     # ISO 27001
│   ├── pci-dss/      # PCI DSS
│   └── fedramp/      # FedRAMP
├── policies/         # Organizational policies
└── evidence/         # Compliance evidence collection
```

## Components

| Directory | Purpose |
|-----------|---------|
| [frameworks/](frameworks/) | Control mappings for compliance frameworks |
| [policies/](policies/) | Organizational security and data policies |
| [evidence/](evidence/) | Evidence collection automation and templates |
