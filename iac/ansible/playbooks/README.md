# Ansible Playbooks

Automation playbooks for provisioning and managing VM-based workloads.

## Playbooks

| Playbook | Purpose |
|----------|---------|
| `setup-gpu-node.yaml` | Configure GPU Droplet with NVIDIA drivers and Docker |
| `deploy-vllm.yaml` | Deploy vLLM model serving |
| `deploy-uptime-kuma.yaml` | Deploy Uptime Kuma monitoring |
| `update-all.yaml` | Update all managed hosts |
